## 中文更新日志

### 全新 WinUI 3 界面与 .NET 10 架构
- 将核心逻辑拆分至基于 .NET 10 的 `Netch.Core`，移除旧版 WinForms 前端，推出全新 WinUI 3 桌面应用 `Netch.App`（单文件自包含便携包，运行入口为 `Netch.App.exe`）。
- 重构主页、节点、模式、场景、日志、设置、下载与关于页面，新增系统托盘快捷菜单、场景全局快捷键、多选批量操作栏，以及支持订阅 / Clash YAML 文件 / 剪贴板 / 手动输入的分步欢迎向导。
- 内置 7 种语言词典（简体中文、繁體中文、English、العربية、日本語、Русский、فارسی），语言选择器直接显示无地区后缀的本地语言名，并支持外置 `i18n/` 自定义覆盖。
- 新增统一多核心日志解析器（`LogLineParser`），整合各代理与辅助核心日志展示；核心与辅助进程全程无窗口运行。

### 现代代理核心与协议支持
- 集成 **Mihomo**（默认核心）、**sing-box**（随附 `libcronet.dll` 支持 NaiveProxy / MASQUE）、**Xray-core**（用于需 Xray 支持的 XHTTP 节点）、**tun2socks**、**AioDNS**、**pcap2socks** 与 **WinTUN**，支持构建期 SHA-256 校验以及应用内可暂停、可回滚的核心与规则更新。
- 扩展协议解析、统一校验、核心配置生成与节点编辑支持，覆盖 **VLESS**（Vision / REALITY / XHTTP）、**VMess**、**Trojan**、**Shadowsocks**、**ShadowsocksR**、**WireGuard**、**Hysteria2**（端口跳跃、混淆及增量参数）、**TUIC**、**AnyTLS**（空闲会话参数）、**NaiveProxy**、**MASQUE**、**ShadowTLS**、**SSH**、**SOCKS5** 与 **HTTP**。
- 支持从订阅链接、剪贴板和本地文件（`.yaml` / `.yml` / `.txt`）导入 **Clash YAML** 节点，隔离订阅与本地导入分组并支持原子分组重命名。

### 混合真实连通性测速与 NAT 检测
- 新增 Hybrid、URLTest、TCPing、ICMPing 测速模式，通过 `CoreDelayTester` 复用 Mihomo / sing-box / Xray 批量 SOCKS5 探测，支持 Mihomo 隧道就绪等待、异常节点二分定位（poison-pill bisection）、按地址族隔离的 TTL DNS 缓存与可取消的流式界面更新。
- UDP NAT 检测升级至 RFC 5780（`Stun.Net` 10.0.10），刷新 STUN 预设列表，支持 IPv4 优先 / IPv6 回退、明确总超时，并区分 `UnsupportedServer` 与 `Incomplete` 状态。

### 网络转发、游戏加速与稳定性
- 进程模式代理 DNS 复用单个长期 SOCKS5 UDP 关联；提升转发线程至最高优先级，UDP 缓冲区扩大至 1 MiB、TCP 缓冲区扩大至 16 KiB，启用 TCP `TCP_NODELAY` 与 UDP 散布/聚集发送。
- 新增“游戏合集”进程模式（涵盖 EA App、Steam、Rockstar/GTA、PUBG、CS2 及 EasyAntiCheat、BattlEye、EA AntiCheat、FACEIT 反作弊服务）；进程规则预编译且不区分大小写，子进程沿父进程链最多追溯 6 层并防范 PID 复用误匹配；支持加速期间提升进程优先级并关闭 EcoQoS（`GameProcessBoost`），进程模式流量统计改读 Redirector 计数以降低 CPU 占用。
- 合并 Redirector PR #1207–#1209（修复 `172.16.0.0/12` 内网绕过规则、规则仅编译一次、补充双栈 IPv6 的 IPv4 映射地址 `::ffff:` 回环与内网绕过规则），修复 Windows 11 停止卡死、TCP 转发关闭竞态及 IOCP/DNS/SOCKS 可靠性问题，并同步更新 WFP 示例驱动与 C API。

## English Changelog

### New WinUI 3 Frontend & .NET 10 Architecture
- Extracted the UI-agnostic core into `Netch.Core` on .NET 10, removed the legacy WinForms frontend, and introduced `Netch.App` (WinUI 3) packaged as a self-contained single-executable portable build (`Netch.App.exe`).
- Rebuilt the Home, Nodes, Modes, Scenes, Logs, Settings, Downloads, and About pages with a system tray flyout, global scene hotkeys, multi-select batch action bars, and a tabbed Welcome wizard supporting Subscriptions, Clash YAML files, Clipboard, and Manual entry.
- Embedded 7 built-in localizations (`zh-CN`, `zh-TW`, `en-US`, `ar`, `ja-JP`, `ru`, `fa-IR`) using region-free native language names, with support for external `i18n/` overrides.
- Added unified multi-core log normalization (`LogLineParser`) and kept all proxy/helper subprocesses windowless.

### Modern Proxy Cores & Protocol Support
- Bundled **Mihomo** (default), **sing-box** (with sibling `libcronet.dll` for NaiveProxy / MASQUE), **Xray-core** (for XHTTP), **tun2socks**, **AioDNS**, **pcap2socks**, and **WinTUN**, featuring SHA-256 verified build-time fetching and pausable, rollback-safe in-app core and rule updates.
- Expanded parsing, unified validation, config generation, and WinUI node editor coverage across **VLESS** (Vision / REALITY / XHTTP), **VMess**, **Trojan**, **Shadowsocks**, **ShadowsocksR**, **WireGuard**, **Hysteria2** (port hopping, obfuscation, incremental options), **TUIC**, **AnyTLS** (idle session settings), **NaiveProxy**, **MASQUE**, **ShadowTLS**, **SSH**, **SOCKS5**, and **HTTP**.
- Added **Clash YAML** node import from subscriptions, clipboard, and local files (`.yaml` / `.yml` / `.txt`), with isolated group naming and atomic group renaming.

### Hybrid Real-Connection Latency Probing & NAT Detection
- Implemented Hybrid, URLTest, TCPing, and ICMPing delay test modes via `CoreDelayTester` reusing Mihomo / sing-box / Xray batch SOCKS5 probes, with Mihomo tunnel readiness checks, poison-pill bisection, address-family-isolated TTL DNS caching, and cancelable streaming UI updates.
- Upgraded UDP NAT detection to RFC 5780 (`Stun.Net` 10.0.10) with refreshed STUN presets, IPv4-first / IPv6 fallback, bounded timeouts, and explicit `UnsupportedServer` / `Incomplete` reporting.

### Redirector Forwarding, Game Acceleration & Reliability
- Shared a single long-lived SOCKS5 UDP association for proxied DNS in process mode; elevated forwarding threads to highest priority, raised UDP buffers to 1 MiB and TCP buffers to 16 KiB, enabled TCP `TCP_NODELAY`, and adopted scatter/gather UDP sends.
- Added the **Game Collection** process mode (EA App, Steam, Rockstar/GTA, PUBG, CS2, EasyAntiCheat, BattlEye, EA AntiCheat, FACEIT), case-insensitive precompiled regex rules, up-to-6-level parent chain matching with PID-reuse protection, optional `GameProcessBoost` (AboveNormal priority and EcoQoS disabled), and direct Redirector traffic counters without ETW overhead.
- Merged Redirector PRs #1207–#1209 (`172.16.0.0/12` bypass fix, one-time regex compilation, IPv4-mapped IPv6 `::ffff:` loopback and intranet bypass rules), fixed Windows 11 stop hangs, TCP relay shutdown races, and IOCP/DNS/SOCKS edge cases, and updated the WFP demo driver and C API.
