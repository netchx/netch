## 亮点

- **代理 DNS 复用连接**：进程模式下的 DNS 查询共享同一个 SOCKS5 UDP 关联，首次访问网站和游戏登录不再为每个域名单独握手。
- **游戏时更稳定**：加速期间 Netch 与代理核心以“高于正常”优先级运行并关闭 Windows 电源节流（EcoQoS），Redirector 转发线程以高优先级运行。
- **新增“游戏合集”模式**：EA App + EA 游戏、Steam + Steam 游戏、Rockstar Games + GTA 全家桶、PUBG、CS2，包含 EasyAntiCheat、BattlEye、EA AntiCheat、FACEIT 与子进程。

## 网络转发

- UDP 转发缓冲区扩大到 1 MiB，TCP 转发缓冲区扩大到 16 KiB。
- Release 版不再逐连接、逐包写日志；ICMP 模拟延迟不再阻塞驱动回调线程。
- 进程规则不区分大小写；“包括子进程”沿父进程链最多追溯 6 层，并排除 PID 复用造成的误匹配。
- 进程模式的流量统计改为读取 Redirector 计数，不再启动系统级内核网络追踪。

## 缺陷修复

- 节点测速取三次探测中的最佳成功结果，不再因最先返回的失败结果误报。
- DNS 解析不再全局串行，一个慢域名不会拖住所有测速和启动。
- 修复快速停止/启动后 NAT、HTTP 检测互相干扰并停留在“Testing”的问题；NAT 检测最长 20 秒。
- 修复单节点测速不显示结果、启动后测速间隔为 0 时持续探测、通过代理更新订阅失败后代理未停止。
- 代理核心提前退出时立即报错，不再等待 50 秒。
- 修复进程模式规则校验后规则残留的问题。

## 使用说明

> [!NOTE]
> “游戏合集”模式会代理 Steam 客户端本身，Steam 下载游戏也会经过代理。大量下载前可临时切换到“Steam Games”模式。

> [!TIP]
> 如需关闭进程优先级优化，在 `data\settings.json` 中设置 `"GameProcessBoost": false`。

TUIC、AnyTLS、NaiveProxy 节点需要 sing-box，请将 Windows x64 版 `sing-box.exe` 放到 `bin` 目录。

完整更新日志见 [README](https://github.com/cbear2024/netch#更新日志)。
