> [!NOTE]
> **Netch 2.1.0** 在 2.0.0 基础上新增多模式场景组合、External CLI 节点与按协议自定义核心、进程内 C# AioDNS（支持 DoH / DoT）、运行时依赖自检、显著瘦身的双形态便携包（`.zip` / `.7z`）以及节点列表排序与双测速改进。
>
> **Netch 2.1.0** builds on 2.0.0 with multi-mode scene composition, External CLI nodes and per-protocol custom cores, in-process C# AioDNS (DoH/DoT), runtime dependency checks, significantly slimmed dual portable packages (`.zip` / `.7z`), and node list sorting and delay-test improvements.

## 中文更新日志

### 多模式场景组合与 Fluent 场景编辑器
- **多模式组合与并发执行**：单个场景支持多选并按序合并多个**进程模式**，且可与**网页代理**或**共享模式**并发运行；**TUN 模式**支持多选合并路由（与前述三类模式互斥）。
- **多控制器生命周期与热规则**：支持多控制器按序启动与逆序（LIFO）停止、ETW 带宽统计回退，以及场景级热规则 overlay 持久化。
- **Fluent 场景编辑体验**：重构「场景」编辑对话框为统一的 Fluent 模式列表卡片，内嵌组合冲突提示与置顶「已选」分组，并在场景卡片上展示语义化模式类型徽章。

### External CLI 节点与按协议自定义核心
- **External CLI 外部节点**：新增 External CLI 节点类型，可直接启动第三方 SOCKS5 命令行代理（网页代理 / PAC 模式下自动经 Mihomo 桥接 HTTP），内置进程模式回环绕过与日志脱敏，跳过不适用的内置测速与分享链接导出。
- **按协议自定义核心与配置模板**：新增「设置 → 自定义核心」，支持按协议绑定自定义可执行文件、工作目录、命令行参数模板与配置文件模板（支持 `{?key:...}` 条件块、`{a|b|lit}` 回退、IPv6 `host:port` 占位符、预设模板选择与实时预览）。
- **优先级调度与全流程接入**：按「节点 → 订阅 → 协议默认 → 内置核心」优先级解析实际运行核心；支持在节点编辑器、订阅分组与批量操作中指定核心，并在导入匹配协议的节点时提示绑定。

### 内置 C# AioDNS、依赖自检与更新限流缓存
- **进程内 C# AioDNS**：以内置 C# `AioDnsServer` 取代外置 Go `aiodns.bin`，原生支持 UDP / TCP / DoT / DoH 上游 DNS 与 TUN 预解析路由，设置页新增自定义 DNS / STUN / 测速地址预设。
- **运行时环境与依赖自检**：新增 WinUI 启动前 Windows 10 1809+ 系统版本检查、加速前按目标核心与模式的定向预检（`EnvironmentChecker`）与含操作指引的依赖弹窗，并在「关于」页展示运行环境诊断。
- **GitHub API 限流保护与 ETag 缓存**：下载中心新增持久化 ETag / 速率限制缓存（`update-cache.json`）、可配置的自动检查间隔，以及正式版通道免 API `/releases/latest` 检查。

### 双形态精简发行包与 `.7z` 归档
- **双部署形态支持**：同步提供**自带框架版**（`self-contained`，内置 `.NET 10` 与 `Windows App SDK` 运行时，开箱即用）与**系统框架版**（`framework-dependent`，体积更小，需系统安装 `.NET 10 Runtime (x64)`），应用内自动更新匹配当前部署形态，并在「关于」页标注当前形态。
- **包体积大幅精简**：将 WinUI 依赖从整套 `Microsoft.WindowsAppSDK` 元包精简为 `Microsoft.WindowsAppSDK.WinUI` 与 `Runtime`，以原生 C# `StunClient5389Udp` 与 `AsyncPrimitives` 取代 `Stun.Net` 和 `Microsoft.VisualStudio.Threading`（移除冗余 WPF 运行时、`dtls_native.dll` 及多余语言/调试附属文件）。
- **`.7z` 与高压缩 `.zip`**：每类包均同步发布固实高压缩 `.7z` 归档与 `.zip` 归档（`SmallestSize`）。

### 节点列表、界面修复与文档
- **排序与双模式快捷测速**：节点页支持点击「名称」「核心」「延迟」列头排序（未测速与异常节点自动置底），工具栏提供「URL 测速（Hybrid）」与「TCP 延迟（TCPing）」双分裂按钮，默认测试当前可见列表且不修改全局默认测速模式。
- **体验修复与文档**：修复订阅分组右键菜单「更新」项在更新完成后保持禁用的问题，优化节点页状态提示居中布局，新增英文 `README.en.md` 与顶部快速导航链接。

### 内置组件与依赖更新

- 移除外置 `aiodns.bin`（已改为进程内 C# AioDNS 实现）。
- 更新 `Microsoft.Diagnostics.Tracing.TraceEvent` 至 `4.0.2`。

## English Changelog

### Multi-Mode Scenes & Fluent Scene Editor
- **Multi-Mode Composition & Concurrent Execution**: A single Scene can now select and merge multiple **Process Mode** rules in order and run concurrently with **Web Proxy** or **Share Mode**; multiple **TUN Mode** rules can also be merged together (mutually exclusive with the other three mode types).
- **Multi-Controller Lifecycle & Hot Rules**: Added ordered startup and LIFO teardown across controllers, ETW bandwidth fallback, and scene-scoped hot-rule overlay persistence.
- **Fluent Scene Editor**: Redesigned the Scene editor dialog with a unified Fluent mode list card, inline composition warnings, a pinned Selected group in the mode flyout, and semantic mode type badges on Scene cards.

### External CLI Nodes & Per-Protocol Custom Cores
- **External CLI Nodes**: Added the External CLI node type to launch third-party SOCKS5 command-line binaries, with automatic HTTP bridging via Mihomo in Web Proxy / PAC mode, Process Mode loopback bypass, redacted logs, and skipped incompatible delay tests / share-link exports.
- **Per-Protocol Custom Cores & Config Templates**: Added **Settings → Custom Cores** to bind custom executables, working directories, CLI argument templates, and config templates per protocol (supporting `{?key:...}` conditionals, `{a|b|lit}` fallbacks, IPv6 `host:port` placeholders, per-protocol presets, and live preview).
- **Priority Resolution & Full Integration**: Resolves the effective core in **Node → Subscription → Protocol Default → Built-in Core** order, wired across the Node Editor, subscription groups, batch actions, and import prompts.

### In-Process C# AioDNS, Dependency Checks & Cached Update Throttling
- **In-Process C# AioDNS**: Replaced the external Go `aiodns.bin` helper with an in-process C# `AioDnsServer` supporting UDP, TCP, DoT, and DoH upstreams, TUN pre-resolved SOCKS5 routing, and customizable DNS / STUN / delay-test endpoint presets in Settings.
- **Runtime Dependency & Pre-Flight Checks**: Added a pre-WinUI Windows 10 1809+ check, targeted core/mode pre-flight validation (`EnvironmentChecker`) with actionable dependency dialogs before acceleration, and environment diagnostics on the About page.
- **GitHub Rate-Limit Protection & ETag Caching**: Added persistent ETag and rate-limit caching (`update-cache.json`) in Downloads, configurable auto-check intervals, and API-free `/releases/latest` checks for stable channels.

### Slimmed Dual Packages & `.7z` Archives
- **Dual Deployment Flavors**: Ships both **Self-Contained** (bundles `.NET 10` and `Windows App SDK`, zero extra runtime required) and **Framework-Dependent** (smaller package using system `.NET 10 Runtime (x64)`) single-file archives; in-app updates automatically select the matching flavor and display the deployment mode on the About page.
- **Significantly Smaller Footprint**: Switched from the full `Microsoft.WindowsAppSDK` metapackage to `Microsoft.WindowsAppSDK.WinUI` and `Runtime`, and replaced `Stun.Net` and `Microsoft.VisualStudio.Threading` with native C# `StunClient5389Udp` and `AsyncPrimitives` (dropping the bundled WPF runtime, `dtls_native.dll`, and unused locale/debug artifacts).
- **Solid `.7z` & Compressed `.zip`**: Publishes both solid `.7z` and `SmallestSize` `.zip` archives for each deployment flavor.

### Node List, UI Fixes & Documentation
- **Column Sorting & Dual Visible-List Delay Tests**: Added clickable Name, Core, and Latency column sorting on the Nodes page (keeping untested and invalid nodes at the bottom), plus split **URL Test (Hybrid)** and **TCP Latency (TCPing)** actions targeting visible nodes by default without overwriting the global delay-test mode.
- **Polish & Documentation**: Fixed the subscription group context menu Update item staying disabled after updates, vertically centered the Nodes page empty/status state, and added `README.en.md` with quick navigation links.

### Bundled Components & Dependencies
- Updated bundled **sing-box** and sibling `libcronet.dll` to **`v1.14.5`** (NaiveProxy `154.0.8037.49-2`).
- Removed external `aiodns.bin` (replaced by the in-process C# AioDNS implementation).
- Updated `Microsoft.Diagnostics.Tracing.TraceEvent` to `4.0.2`.
