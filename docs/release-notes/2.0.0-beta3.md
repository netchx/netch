## 中文更新日志

### Mihomo 协议扩展（TrustTunnel / Mieru / ShadowQUIC / AmneziaWG）
- 新增 `TrustTunnel`（支持 `trusttunnel://`、`tt://` RFC 9000 varint TLV 深链、内联 PEM 与 ECH）、`Mieru`（支持 `mierus://`、`mieru://`、TCP/UDP 与单端口范围）、`ShadowQUIC`（支持 `shadowquic://`、QUIC v1/v2、0-RTT 与 BBR/Brutal）及 `AmneziaWG`（支持 `amneziawg://`、`awg://`、`wg://` AWG 参数自动识别与 v1/v2/v3 选项）的数据模型、分享链接解析与生成、Clash YAML 导入、统一校验、`MihomoConfig` 配置生成与 WinUI 节点编辑支持。
- 加固上述协议的解析、校验与配置生成防护（拒绝非法主机名、显式 `:0` 端口及畸形数值查询参数，统一大小写与空白字段处理及拥塞控制/传输下拉选项），并补充离线 `mihomo -t` 校验与回归单元测试。

### 进程模式 IP 过滤、连接追踪与连接页面
- 在 Redirector 与 `NFController` 中新增进程模式目标 IPv4/IPv6/CIDR 过滤（`HandleIPs` / `BypassIPs`）与原子规则事务支持，进程模式编辑器同步开放 IP 规则编辑与搜索检索。
- 新增实时/已关闭连接追踪（`ConnectionTrackerService`）与单调事件环形缓冲（可选异步写入 `logging/nf-connections.log`），推出 WinUI **连接**页面（包含实时连接与连接日志视图、独立右对齐上传/下载速率列与三态点击表头排序、可折叠详情抽屉以及热规则暂存/保存），并通过 `INotifyPropertyChanged` 原地槽位更新消除列表滚动闪烁。
- 新增可选 Windows Kernel ETW 未匹配/直连流量监控（`EtwNetworkMonitor`，支持多 Socket TCP 流聚合与定向子网广播过滤），在 Redirector 与 ETW 中绕过 Idle（PID 0）与 System（PID 4），并对 `svchost.exe` 等系统关键进程的热规则添加提供安全防护与确认提示。

### 设置页重构、WinUI 体验与单文件打包修复
- 将 **设置** 页面重构为 165px 左侧分类导航 + 单列分组卡片与行内编辑布局（分离“本地混合端口”与“允许局域网连接”、支持数值回车/失焦校验、行内编辑 GitHub 镜像前缀与核心选项），移除未使用的 `CommunityToolkit.WinUI.Controls.SettingsControls` 依赖包并同步更新 6 种语言词典。
- 为页面与弹窗统一预留 16 DIPs 右侧滚动条间距以防悬浮滚动条遮挡控件，修复居中窗口按显示工作区独立限制宽高的问题，并精简 `README.md` 中的模式与协议表格展示。
- 在 `Netch.App.csproj` 新增 `_InvalidateStaleSingleFileManifest` 构建目标，解决在常规 `dotnet build` 与单文件 `dotnet publish` 之间切换时 `app.manifest` 缓存未重建导致清单重定向缺失的问题。

## English Changelog

### Expanded Mihomo Protocols (TrustTunnel / Mieru / ShadowQUIC / AmneziaWG)
- Added server models, share-link URI parsing/export, Clash YAML import, unified validation, `MihomoConfig` generation, and WinUI node editor fields for `TrustTunnel` (`trusttunnel://`, `tt://` RFC 9000 varint TLV deep-links, inline PEM, and ECH), `Mieru` (`mierus://`, `mieru://`, TCP/UDP, and single port ranges), `ShadowQUIC` (`shadowquic://`, QUIC v1/v2, 0-RTT, and BBR/Brutal), and `AmneziaWG` (`amneziawg://`, `awg://`, `wg://` AWG auto-promotion, and v1/v2/v3 options).
- Hardened parsing, validation, and config guards across all four protocols (rejecting invalid TLV hostnames, explicit `:0` ports, and malformed numeric query parameters while normalizing case-insensitive fields, whitespace-only values, and dropdown selections), and added regression coverage including offline `mihomo -t` schema checks.

### Process-Mode IP Filtering, Connection Tracking & Connections Page
- Added target IPv4/IPv6/CIDR filtering (`HandleIPs` / `BypassIPs`) and atomic rule transactions in Redirector and `NFController`, along with IP rule editing and search support in the Process Mode editor.
- Added live and closed connection tracking (`ConnectionTrackerService`) backed by a monotonic event ring with optional async `logging/nf-connections.log` output, and introduced the WinUI **Connections** page featuring Live Connections, Connection Logs, separate right-aligned Upload/Download columns with three-state clickable header sorting, a collapsible Inspector drawer, hot-rule staging/persistence, and in-place `INotifyPropertyChanged` row updates to eliminate scroll flicker.
- Added optional Windows Kernel ETW monitoring (`EtwNetworkMonitor`) for unmatched/direct process traffic with multi-socket TCP flow aggregation and directed subnet broadcast filtering, bypassed Idle (PID 0) and System (PID 4) sockets in Redirector and ETW, and added `ProcessRuleSafety` guards with confirmation prompts for system processes such as `svchost.exe`.

### Refactored Settings UI, WinUI Polish & Single-File Manifest Fix
- Refactored the **Settings** page into a 165px left category rail with single-column grouped cards and inline editing (separating Local mixed port and Allow LAN connections, adding Enter/blur numeric validation, and making GitHub mirror prefix and core options editable inline), removed the unused `CommunityToolkit.WinUI.Controls.SettingsControls` package, and updated all 6 built-in i18n dictionaries.
- Reserved a consistent 16 DIP scrollbar gutter across pages and dialogs so WinUI overlay scrollbars never obscure controls, clamped centered window width and height independently to the display work area, and compacted the `README.md` mode and protocol tables.
- Added `_InvalidateStaleSingleFileManifest` in `Netch.App.csproj` before `CreateWinRTRegistration` so switching between `dotnet build` and single-file `dotnet publish` always regenerates `app.manifest` cleanly.
