> [!NOTE]
> **Netch 2.0.0** 是基于 **WinUI 3** 与 **.NET 10** 全面重构的首个正式版本，面向 Windows 10 1809+ / Windows 11（x64）。采用单文件自包含便携包发布，无需再手动安装 .NET 运行库。
>
> **Netch 2.0.0** is the first stable release of the **WinUI 3** and **.NET 10** rewrite for Windows 10 1809+ / Windows 11 (x64). Distributed as a self-contained portable package with no manual .NET runtime installation required.

## 中文更新日志

### 全新 WinUI 3 桌面体验与 .NET 10 架构
- **全面重写与架构解耦**：移除旧版 WinForms 界面，将核心拆分为基于 .NET 10 的 `Netch.Core`，推出全新 WinUI 3 应用 `Netch.App`（入口变更为 `Netch.App.exe`），完整内置 .NET 10 与 Windows App SDK 运行时。
- **场景化交互与全新页面**：重构「场景」「节点」「模式」「连接」「下载」「日志」「设置」「关于」八大页面，支持浅色 / 深色 / 跟随系统主题、场景卡片一键加速、全局快捷键、系统托盘快捷菜单、多选批量操作、二维码分享与分步欢迎向导。
- **多语言与统一日志**：内置 7 种界面语言（简体中文、繁體中文、English、日本語、Русский、العربية、فارسی），支持外置 `i18n/` 自定义词典；新增统一多核心日志解析，所有代理与辅助进程全程无窗口运行。

### 多核心自动调度与 19 种代理协议
- **多核心开箱即用**：内置 **Mihomo**（默认核心）、**sing-box**（随附 `libcronet.dll` 支持 NaiveProxy）、**Xray-core**（处理需 Xray 支持的 XHTTP 特性），按节点协议与传输参数自动分流。
- **扩展至 19 种协议**：完整覆盖解析、统一校验、核心配置生成与节点编辑，支持 **VLESS**（Vision / REALITY / XHTTP）、**VMess**、**Trojan**、**Shadowsocks**（含 2022 / 插件 / `ssd://`）、**ShadowsocksR**、**ShadowTLS**（v1–v3 / UoT）、**Hysteria2**（端口跳跃 / 混淆 / BBR）、**TUIC**、**AnyTLS**、**TrustTunnel**、**Mieru**、**ShadowQUIC**、**WireGuard**、**AmneziaWG**、**NaiveProxy**、**MASQUE**（需替换支持 `masque-client` 的 sing-box）、**SOCKS5**（含 UoT）、**HTTP / HTTPS** 与 **SSH**。
- **Clash YAML 与订阅导入**：支持从订阅链接、剪贴板与本地文件（`.yaml` / `.yml` / `.txt`）导入 Clash YAML 节点，订阅与本地分组相互隔离并支持重命名。

### 进程加速优化、IP 过滤与实时连接监控
- **面向低延迟游戏的转发调优**：进程模式代理 DNS 复用单个长期 SOCKS5 UDP 关联；开启 TCP `TCP_NODELAY`、UDP 散布/聚集发送，将 UDP / TCP 转发缓冲区分别扩大至 1 MiB / 16 KiB 并提升转发线程优先级；加速期间自动提升核心进程优先级并关闭 Windows 电源节流（EcoQoS），流量统计直接读取 Redirector 计数以降低 CPU 占用。
- **游戏规则与精准过滤**：新增「游戏合集」模式（涵盖 EA App、Steam、Rockstar/GTA、PUBG、CS2 及主流反作弊服务），内置超百套模式规则；进程规则预编译且不区分大小写，子进程沿父进程链最多追溯 6 层并防范 PID 复用误匹配；新增进程模式目标 IPv4 / IPv6 / CIDR 代理与绕过过滤。
- **实时连接监控与热规则**：新增「连接」页面，支持实时连接与连接日志视图、独立上传/下载速率列与点击排序、详情抽屉、可选 Windows Kernel ETW 未匹配/直连流量观测，以及加速期间暂存并热应用进程与目标 IP 规则（内置 `svchost.exe` 等系统关键进程防护）。
- **稳定性与兼容性修复**：合并 Redirector PR #1207–#1209（修复 `172.16.0.0/12` 内网绕过、规则仅编译一次、补充 IPv4 映射 IPv6 `::ffff:` 回环与内网绕过），修复 Windows 11 停止卡死及 TCP 转发关闭竞态。

### 新增网页代理模式（PAC / Global / Manual）
- 新增免驱动的「网页代理」模式，提供 **PAC 自动分流**、**全局系统代理** 与 **仅本地混合端口（HTTP/SOCKS5）** 三种策略及 4 套开箱预设。
- 集成 `Loyalsoldier/v2ray-rules-dat` 域名规则表（`proxy-list`、`gfw`、`direct-list`），支持自定义域名规则与本地自定义 PAC 脚本；基于 WinINet 管理并在异常退出重启后自动恢复系统代理状态。

### 联机质量诊断与内建更新管理
- **混合测速与 NAT 检测**：新增 Hybrid、URLTest（真连接）、TCPing、ICMPing 四种测速模式，支持批量 SOCKS5 探测、异常节点二分定位与可取消流式结果更新；集成 `Loyalsoldier/geoip` 出口国家识别；UDP NAT 检测升级至 **RFC 5780**（`Stun.Net 10.0.10`），支持 IPv4 优先 / IPv6 回退。
- **内建下载与更新中心**：在「下载」页统一管理代理核心、游戏模式规则与 PAC 规则更新，支持暂停续传、SHA-256 校验、版本回滚，以及直连、代理和自定义 GitHub 镜像通道。

### 从 1.9.x 升级说明
- **请勿直接覆盖旧版目录**：2.0 启动入口已从 `Netch.exe` 更改为 `Netch.App.exe`，请完整解压至全新目录运行。
- **配置迁移建议**：建议备份旧版 `data/settings.json` 后按需迁移，或在新版中重新导入订阅 / Clash YAML。
- **UDP 协议提示**：进程、TUN、共享模式依赖 UDP 转发；`HTTP / HTTPS`、`SSH`、`NaiveProxy` 不支持 UDP（适合网页代理模式），`ShadowTLS` 用于游戏加速需开启 UoT。

## English Changelog

### Brand-New WinUI 3 UI & .NET 10 Architecture
- **Full Rewrite & Modular Core**: Replaced the legacy WinForms client with `Netch.App` (WinUI 3, launched via `Netch.App.exe`) over a UI-agnostic .NET 10 `Netch.Core`, shipped as a self-contained single-executable portable bundle with embedded .NET 10 and Windows App SDK runtimes.
- **Scene-Centric Desktop Experience**: Rebuilt Scenes, Nodes, Modes, Connections, Downloads, Logs, Settings, and About pages with Light/Dark/System themes, one-click Scene cards, global hotkeys, a system tray flyout, multi-select batch actions, QR code sharing, and a tabbed onboarding wizard.
- **Localization & Unified Logging**: Built-in 7 languages (`简体中文`, `繁體中文`, `English`, `日本語`, `Русский`, `العربية`, `فارسی`) with external `i18n/` overrides, unified multi-core log normalization, and windowless subprocess execution.

### Multi-Core Auto-Dispatch & 19 Protocols
- **Batteries-Included Proxy Cores**: Bundles **Mihomo** (`v1.19.34`, default), **sing-box** (`v1.14.4` with sibling `libcronet.dll` for NaiveProxy), and **Xray-core** (`v26.11.9` for XHTTP features), automatically selecting the best core per node.
- **19 Supported Protocols**: End-to-end URI parsing/export, validation, config generation, and WinUI node editing for **VLESS** (Vision / REALITY / XHTTP), **VMess**, **Trojan**, **Shadowsocks** (incl. 2022 / plugins / `ssd://`), **ShadowsocksR**, **ShadowTLS** (v1–v3 / UoT), **Hysteria2**, **TUIC**, **AnyTLS**, **TrustTunnel**, **Mieru**, **ShadowQUIC**, **WireGuard**, **AmneziaWG**, **NaiveProxy**, **MASQUE** (requires sing-box `>= 1.15.0-alpha.7`), **SOCKS5** (incl. UoT), **HTTP / HTTPS**, and **SSH**.
- **Clash YAML Import**: Import nodes from subscription URLs, clipboard, or local files (`.yaml` / `.yml` / `.txt`) with isolated group management.

### Game Acceleration, Target IP Filtering & Live Connections Monitor
- **Low-Latency Forwarding**: Shared long-lived SOCKS5 UDP association for proxied DNS, TCP `TCP_NODELAY`, scatter/gather UDP sends, 1 MiB UDP / 16 KiB TCP buffers, elevated forwarding thread priority, automatic `GameProcessBoost` (AboveNormal priority + EcoQoS disabled), and direct Redirector traffic counters.
- **Smarter Process Rules**: Added the **Game Collection** mode (EA App, Steam, Rockstar/GTA, PUBG, CS2, and major anti-cheat services) alongside 100+ built-in mode files; precompiled case-insensitive process rules, 6-level parent-chain matching with PID-reuse protection, and target IPv4/IPv6/CIDR filtering (`HandleIPs` / `BypassIPs`).
- **Connections Page & Hot Rules**: Real-time active connections and closed connection logs, independent Upload/Download rate columns with clickable sorting, collapsible Inspector drawer, optional Windows Kernel ETW monitoring for unmatched/direct traffic, and live hot-rule staging/apply with critical system-process safeguards.
- **Reliability Fixes**: Merged Redirector PRs #1207–#1209 (`172.16.0.0/12` bypass fix, one-time rule compilation, `::ffff:` IPv4-mapped IPv6 loopback/intranet bypass) and resolved Windows 11 stop hangs and TCP shutdown races.

### WebProxy Mode (PAC / Global / Manual)
- Added driverless **WebProxy** mode supporting **PAC** auto-routing, **Global** system proxy, and **Manual** local mixed HTTP/SOCKS5 port strategies with 4 presets.
- Integrated `Loyalsoldier/v2ray-rules-dat` lists (`proxy-list`, `gfw`, `direct-list`), custom domain rules, local custom PAC scripts, and crash-safe WinINet system proxy restoration.

### Diagnostics & In-App Download Manager
- **Latency & NAT Diagnostics**: Added Hybrid, URLTest, TCPing, and ICMPing delay testing with batch SOCKS5 probing and poison-pill bisection, GeoIP exit country lookup, and RFC 5780 UDP NAT detection (`Stun.Net 10.0.10`).
- **In-App Updates**: Manage proxy cores, game mode rules, and PAC rule lists in Downloads with pause/resume, SHA-256 verification, rollback safety, and Direct / Proxy / GitHub Mirror channels.

### Upgrading from 1.9.x
- **Clean Extraction Recommended**: The entry executable changed from `Netch.exe` to `Netch.App.exe`. Extract to a fresh folder rather than overwriting a 1.9.x directory.
- **UDP Requirement**: Process, TUN, and Share modes rely on UDP forwarding. `HTTP / HTTPS`, `SSH`, and `NaiveProxy` do not support UDP (intended for WebProxy mode); `ShadowTLS` requires UoT enabled.
