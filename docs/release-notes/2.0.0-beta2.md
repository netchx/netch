## 中文更新日志

### 网页代理模式（Global / PAC / Manual）
- 新增 `WebProxyMode`（支持 `PAC` 自动分流、`Global` 全局系统代理与 `Manual` 仅本地混合端口三种策略）及对应的默认预设（`PAC (Proxy List)`、`PAC (Bypass China)`、`Global Web Proxy`、`Local Proxy Only`）。
- 集成 `Loyalsoldier/v2ray-rules-dat` 规则表（`proxy-list.txt`、`gfw.txt`、`direct-list.txt`），同时支持自定义规则与本地自定义 PAC 脚本；通过精简 ES3 兼容的 `PacScriptBuilder` 与本地回环 `PacHttpServer` 生成并托管 PAC。
- 通过 `SystemProxyService` 管理 WinINet 系统代理，支持异常退出后的状态保存与启动恢复；`Manual` 策略仅监听本地混合 HTTP / SOCKS5 端口而不修改系统代理设置；并在“设置 -> 网页代理 · PAC”开放端口与默认绕过列表配置。

### 下载管理器集成 PAC 规则更新
- 在“下载”页面新增独立的 **PAC 规则** 标签页，基于 `Loyalsoldier/v2ray-rules-dat` Release 标签与 `data/pac/.manifest.json` 跟踪本地版本，支持待更新角标计数、下载进度与暂停控制、下载记录以及候选源失败回退。
- 支持单个与批量更新 PAC 规则表，批量更新结束后按需统一重载当前正在运行的 PAC 场景，并在模式编辑器保留自定义规则地址下载入口。

### 欢迎向导、多语言与发布流程完善
- 欢迎向导“选择加速对象”新增 **网页代理** 卡片与策略选择，同时为 **全部流量（TUN）** 新增路由模式选择（全局 TUN、绕过局域网与中国大陆、仅绕过局域网）。
- 调整欢迎向导“手动添加”常用协议顺序为 `SOCKS`、`Shadowsocks`、`ShadowsocksR`、`AnyTLS`、`VLESS` 与“更多协议”。
- 同步更新 6 种语言词典（`zh-CN`、`zh-TW`、`ja-JP`、`ru`、`ar`、`fa-IR`），重写项目 `README.md`，并在 `release.yml` 中直接使用 tag 名称作为 GitHub Release 标题。

## English Changelog

### WebProxy Mode (Global / PAC / Manual)
- Added `WebProxyMode` supporting **PAC** auto-proxy, **Global** system proxy, and **Manual** local-port-only strategies, along with four built-in presets (`PAC (Proxy List)`, `PAC (Bypass China)`, `Global Web Proxy`, and `Local Proxy Only`).
- Integrated `Loyalsoldier/v2ray-rules-dat` rule lists (`proxy-list.txt`, `gfw.txt`, `direct-list.txt`) alongside custom domain rules and local custom PAC scripts, served via compact ES3-compatible `PacScriptBuilder` output and loopback `PacHttpServer`.
- Added crash-safe WinINet system proxy management (`SystemProxyService`), local mixed HTTP/SOCKS5 listening without altering system proxy under `Manual`, and **Web proxy · PAC** port and default bypass settings.

### PAC Rule Downloads in Download Manager
- Added a dedicated **PAC rules** tab in Downloads backed by `Loyalsoldier/v2ray-rules-dat` releases and `data/pac/.manifest.json` version tracking, complete with pending badge counts, transfer progress/pause controls, download history, and CDN fallback retries.
- Supported single and batch PAC updates with deferred active-scene reload after batch completion, while keeping custom rule URL downloads available in the Mode Editor.

### Onboarding Wizard, Localization & Release Workflow
- Added the **Web proxy** card and strategy dropdown to Step 2 of the onboarding wizard, plus a routing mode selector for **All traffic (TUN)** (Global TUN, Bypass LAN & China, Bypass LAN).
- Reordered featured manual-add protocols in the wizard to `SOCKS`, `Shadowsocks`, `ShadowsocksR`, `AnyTLS`, `VLESS`, and **More protocols**.
- Updated all 6 localization files (`zh-CN`, `zh-TW`, `ja-JP`, `ru`, `ar`, `fa-IR`), refreshed `README.md`, and updated `release.yml` to use the pushed tag ref directly as the GitHub Release title.
