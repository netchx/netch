> [!NOTE]
> **Netch 2.1.1** 基于 `2.0.0` 构建，重点带来多模式场景组合、External CLI 节点与按协议自定义核心、进程内加密 DNS（DoH / DoT）、运行时依赖自检、大幅瘦身的便携包，以及全新的 **`.7z` 应用内自动更新**能力。
>

>
> **Netch 2.1.1** builds on `2.0.0` with multi-mode scene composition, External CLI nodes and per-protocol custom cores, in-process encrypted DNS (DoH / DoT), runtime dependency checks, significantly smaller portable packages, and **native `.7z` in-app auto-update support**.
>
> To ensure `2.0.0` users can update in-app seamlessly, **`2.1.1` still ships both `.zip` and `.7z` archives; starting from the next release, only `.7z` packages will be published** (natively extracted by `2.1.1+`).

## 中文更新日志

### 亮点速览
- **多模式场景组合**：单个场景支持多选并合并多个进程模式，且可与网页代理或共享模式并发运行；TUN 模式支持多选合并路由。
- **自定义核心与外部节点**：新增 **External CLI** 命令行节点与**按协议自定义核心**，支持模板化配置生成与多层级优先级覆盖。
- **内置加密 AioDNS 与依赖自检**：内置进程内 C# AioDNS（原生支持 DoH / DoT 上游），新增启动与加速前的系统及组件依赖预检。
- **包体积大幅瘦身与 `.7z` 自动更新**：精简 WinUI 运行时与原生组件依赖、同步提供固实 `.7z` 包，并原生支持直接下载解压 `.7z` 更新包（体积更小）。

### 功能新增与改进
- **场景与模式**：重构为 Fluent 风格模式列表卡片，置顶展示已选模式并内嵌互斥/冲突提示；场景卡片新增语义化模式类型徽章，支持多控制器按序启动、逆序停止与场景级热规则持久化。
- **自定义核心与外部节点**：支持第三方 SOCKS5 命令行核心直连或经 Mihomo 桥接为 HTTP 供网页代理使用；「设置 → 自定义核心」支持条件块与回退占位符、IPv6 地址端口格式、常用协议预设与实时预览，按「节点 → 订阅 → 协议默认 → 内置核心」自动生效。
- **DNS、诊断与下载中心**：AioDNS 支持 UDP / TCP / DoT / DoH 上游与 TUN 预解析路由，设置页新增 DNS / STUN / 测速地址预设；新增 Windows 10 1809+ 启动检查、加速前定向环境弹窗与「关于」页诊断导出；下载中心新增本地 ETag 缓存与 GitHub API 限流退避、可调自动检查间隔，以及正式版免 API 快速检查。
- **节点列表与文档**：支持按「名称」「核心」「延迟」列头点击排序（未测速与无效节点自动置底），工具栏提供「URL 测速（Hybrid）」与「TCP 延迟（TCPing）」双快捷操作且不覆盖全局默认测速模式；修复订阅分组右键菜单「更新」在更新后保持禁用的问题，优化节点页空状态居中对齐，并新增英文用户文档 `README.en.md`。

### 发行包与升级说明
- **自带框架版（推荐）**：内置 `.NET 10` 与 `Windows App SDK`，除共享模式需 Npcap / VC++ x64 外开箱即用。
- **系统框架版（更轻量）**：体积更小，需系统预先安装 `.NET 10 Runtime (x64)`。
- **关于 `.zip` 与 `.7z`**：`2.0.0` 用户可直接点击软件内「更新并重启」通过 `.zip` 升级至 `2.1.1`；升级至 `2.1.1+` 后，客户端将在检测到新版时默认下载体积更小的 `.7z` 压缩包并自动完成解压替换，下一版本起不再附带 `.zip`。

## English Changelog

### Highlights
- **Multi-Mode Scene Composition**: Combine and merge multiple Process Mode rules within a single Scene and run concurrently with Web Proxy or Share Mode, or merge multiple TUN Mode route rules together.
- **External CLI & Per-Protocol Custom Cores**: Launch arbitrary SOCKS5 command-line binaries as nodes and override executables, working directories, CLI arguments, and templated configs per protocol.
- **In-Process Encrypted AioDNS & Pre-Flight Checks**: Built-in C# AioDNS with native DoH / DoT upstreams plus startup and pre-connect dependency validation.
- **Slimmer Packages & `.7z` Auto-Updates**: Stripped unused WinUI runtime and legacy dependencies, added solid `.7z` packages, and added native `.7z` extraction to the in-app updater.

### What's New & Improved
- **Scenes & Modes**: Redesigned the Scene editor with a unified Fluent mode card, pinned Selected group, and inline compatibility warnings; added semantic mode badges on Scene cards, ordered controller startup with LIFO teardown, and scene-scoped hot-rule persistence.
- **Custom Cores & External Nodes**: External CLI nodes bridge HTTP automatically via Mihomo in Web Proxy / PAC mode with loopback bypass and redacted logs; **Settings → Custom Cores** supports conditional/fallback template tokens, IPv6-safe `host:port` formatting, protocol presets, and live preview, resolved in **Node → Subscription → Protocol Default → Built-in Core** order.
- **DNS, Diagnostics & Updater**: AioDNS supports UDP / TCP / DoT / DoH upstreams and TUN pre-resolved routing alongside customizable DNS / STUN / latency endpoint presets; added Windows 10 1809+ startup checks, actionable pre-connect dependency dialogs, and About page diagnostics; Downloads adds persistent ETag and rate-limit caching, configurable auto-check intervals, and API-free `/releases/latest` checks for stable builds.
- **Nodes Page & Documentation**: Added clickable **Name**, **Core**, and **Latency** column sorting (keeping untested/invalid nodes at the bottom), split **URL Test (Hybrid)** and **TCP Latency (TCPing)** actions for visible nodes without mutating the default mode, fixed subscription group context menu refresh state, centered the empty status view, and added `README.en.md`.

### Packaging & Upgrade Path
- **Self-Contained (Recommended)**: Bundles `.NET 10` and `Windows App SDK` for zero-dependency launch (Share Mode still requires Npcap and VC++ x64).
- **Framework-Dependent (Lightweight)**: Smaller archive using the system `.NET 10 Runtime (x64)`.
- **`.zip` to `.7z` Transition**: `2.0.0` installations can auto-update directly to `2.1.1` via `.zip`. Starting with `2.1.1`, the in-app updater prefers `.7z` and extracts solid `.7z` archives natively, allowing `.zip` packages to be dropped starting in the next release.

### Bundled Components
- Updated bundled **sing-box** and sibling `libcronet.dll` to **`v1.14.5`** (NaiveProxy `154.0.8037.49-2`).
- Removed external `aiodns.bin` (replaced by built-in C# AioDNS), updated `Microsoft.Diagnostics.Tracing.TraceEvent` to `4.0.2`, and added `SharpCompress 1.0.0` for `.7z` update extraction.
